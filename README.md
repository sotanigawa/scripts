# scripts

A collection of small scripts I use.

## Install

Clone the repository and symlink the scripts you want into a directory on
your `PATH` (e.g. `~/.local/bin`):

```sh
git clone https://github.com/sotanigawa/scripts.git ~/src/scripts
ln -s ~/src/scripts/zcut ~/.local/bin/zcut
```

Each script is independent, so pick only the ones you need.
See the comment at the top of each script for usage and requirements.

## Scripts

- [`drag`](drag) - drag and drop files from the terminal into any GUI app
- [`zcut`](zcut) - extract a page range from the PDF you are viewing in zathura
